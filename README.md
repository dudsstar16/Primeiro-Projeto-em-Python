# Automação de Relatórios de Faturamento com Python

📊 Automação de Relatórios de Faturamento com Python

📌 Objetivo do Projeto

Este projeto tem como objetivo automatizar o processo completo de obtenção, análise e envio de relatórios de faturamento, eliminando tarefas manuais e reduzindo erros operacionais.
A solução realiza desde a abertura do navegador, extração de planilhas em Excel, tratamento dos dados, cálculo de indicadores até o envio automático dessas informações por e-mail, utilizando Python e bibliotecas voltadas à automação e análise de dados.

⚙️ Funcionalidades

Abertura automática do navegador
Extração de planilha em formato Excel
Tratamento e consolidação de dados com Pandas
Cálculo de indicadores de negócio:

Faturamento total
Quantidade total de produtos vendidos


Automação de cliques e interações com o sistema usando PyAutoGUI
Envio automatizado das informações por e-mail
Eliminação de processos manuais repetitivos

📓 O projeto foi desenvolvido em Jupyter Notebook, permitindo visualizar passo a passo a automação, o tratamento dos dados e o cálculo dos indicadores.

🧠 Tecnologias Utilizadas

Python
Pandas → tratamento e análise de dados
PyAutoGUI → automação de processos e interface gráfica
OpenPyXL → leitura e manipulação de arquivos Excel
